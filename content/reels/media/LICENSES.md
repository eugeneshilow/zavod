# Лицензии медиа историй

Каждая картинка и каждое видео в `content/reels/media/<id>/` имеет здесь строку:
`файл · источник (URL) · лицензия · дата`. Файл без строки в ролик не идёт —
это проверяет сам рендер (`scripts/reels/render-story.mjs`). Канон зоны —
[docs/reels.md](../../../docs/reels.md), раздел «История».
