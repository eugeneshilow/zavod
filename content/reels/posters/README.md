# posters — плакаты

По файлу на плакат: одна картинка и одна строка поверх неё.

```json
{
  "id": "red-cloud",
  "image": "assets/posters/red-cloud.png",
  "line": "Машина, которая строит софт, пока ты спишь."
}
```

- `id` — имя файла на выходе: `out/reels/<id>.mp4`.
- `image` — путь к картинке 1024×1536 от корня репозитория.
- `line` — одна строка; она печатается в нижней трети кадра.

Как это собирается — [docs/reels.md](../../../docs/reels.md).
