# Лицензии треков

Одна строка на каждый файл `*.mp3` в этой папке. Формат строки:

```
название · автор · источник (URL) · лицензия · дата добавления
```

Трек, которого нет в этом списке, в ролик не идёт: происхождение неизвестно.
Сюда кладут только royalty-free музыку, которую разрешено вшивать в файл
(например с Pixabay). Музыку из библиотеки Instagram вшивать нельзя — канон
зоны: [docs/reels.md](../../docs/reels.md).
