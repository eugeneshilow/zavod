# cabinet — кабинет покупателя

Дата: 2026-09-23. Кабинет — то, что покупатель завода видит после
витрины: свои ролики, очередь, просмотры. Живёт на поддомене
`app.zavod.today` (локально `app.localhost:<порт>`), внутри проекта это
раут `/cabinet`: запрос с хоста `app.` переписывается на него в
`proxy.ts`. Форма первого экрана снята с шаблона Dashboard библиотеки
HeroUI по кадру, не по коду (⚖️ cabinet-heroui-by-frame,
[journal.md](journal.md)); компоненты — бесплатная `@heroui/react`,
второй набор рядом с shadcn витрины, по одному набору на зону.

## Блоки

Порядок блоков первого экрана читается из этого списка (правило зеркала,
как блоки витрины в [landing/README.md](../landing/README.md)).

1. **Меню** — слева: имя покупателя и тариф; Главная · Ролики · Очередь (со счётчиком) · Просмотры · Настройки; внизу Помощь · Выйти.
2. **Шапка** — «Доброе утро, имя» по московскому времени суток; кнопка «Сделать ролик».
3. **Вкладки** — Обзор · Ролики · Платежи; справа период и «Отчёт».
4. **Показатели** — четыре карточки: в эфире · просмотров за неделю · в очереди · всего роликов.
5. **Графики** — столбики «Выпуск роликов» за две недели с подчислами (неделя · день · всего) и «Лучшие ролики» по просмотрам.
6. **Ролики** — таблица: превью и заголовок с источником новости, статус (в эфире · рендерится · в очереди · ошибка · снят), просмотры, действия (открыть · скачать).

## Стройка

Переносчик — `lib/cabinet.ts`: список блоков читается из этого файла
функцией `cabinetBlocks`, собранное в коде держит `BUILT_BLOCKS`, тест
`tests/cabinet.test.ts` сверяет их. Экраны — `app/cabinet/*`, кирпичи —
`components/cabinet/*`. Данные приходят одной функцией `loadCabinet`,
чистая сборка чисел и строк — `composeCabinet` (тесты без базы).

## Известные края

- Входа нет: до кассы кабинет показывает один демо-аккаунт — канал завода `ruvibecoding` под именем владельца; имя и тариф — константа `DEMO_CUSTOMER` в переносчике. Вход по ссылке на почту — следующий заход.
- «Платежи», «Просмотры» и «Настройки» — заглушки до кассы.
- Ссылки внутри кабинета ведут на `/cabinet/...`, они работают и на `app.`-хосте, и на основном; короткие адреса без префикса появятся вместе с входом.
- Графики нарисованы SVG руками: библиотеки графиков в проекте нет, две картинки её не оправдывают.
