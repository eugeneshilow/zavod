# 21st.dev как источник блоков витрины — срез 2026-09-22

Неизменный срез. Вопрос владельца: «как оптимально подрубиться к
21st.dev, чтобы просто собрать оттуда подходящие для лендоса элементы».
Источники — страницы 21st.dev и shadcn, прочитаны 22.09.2026.

## Что это

Маркетплейс готовых блоков интерфейса: «12,000+ hand-crafted React and
Tailwind CSS components, templates, and shadcn themes»
([21st.dev](https://21st.dev/)). Есть разделы под витрину: hero (1152+),
pricing section (216+), landing-page (69+), testimonials, FAQ, footer.
Блок — файл TSX на Tailwind в формате реестра shadcn.

## Три способа взять блок

1. **Копировать TSX** со страницы блока — руками в проект.
2. **shadcn CLI** — `npx shadcn@latest add <адрес реестра блока>`: файл
   ложится в `components/ui`, зависимости ставятся. Нужен `components.json`
   в проекте (`npx shadcn@latest init`; создаёт `components.json`,
   `lib/utils.ts`, переменные темы; Tailwind v4 и React 19 поддержаны —
   [shadcn/Next](https://ui.shadcn.com/docs/installation/next)).
3. **21st MCP для агента** — `npx @21st-dev/cli@latest init --client claude`;
   сервер `https://21st.dev/api/mcp`, ключ создаётся на
   [21st.dev/mcp](https://21st.dev/mcp). Инструменты: `search` (по
   каталогу, бесплатно, только метаданные), `get_component` (код блока,
   считается копией), `get_inspiration`, `search_logo` (бесплатно),
   `generate` (21st AI, кредиты). Старые ключи Magic сброшены — ключ
   брать свежий.

## Что это значит для завода

- Стек совпадает: Next 16, React 19, Tailwind v4 — блоки встают как есть
  после `shadcn init`. Своего `components.json` у завода нет.
- Десять блоков витрины на бесплатном плане — пять дней по две копии;
  на Builder — один вечер. Галерея примеров и метрика героя — свои
  (живые данные из таблиц), с маркетплейса берётся только форма.
- Их статья «[Nine blocks](https://21st.dev/blog/landing-page-sections)»
  даёт порядок: герой · логотипы · проблема · функции · демо · отзывы ·
  цена · FAQ · призыв; тезис — «порядок совпадает с порядком вопросов
  читателя», блок «проблема» пропускают чаще всего, а он держит
  остальное. В нашем списке блока «проблема» нет — кандидат на
  добавление между героем и «как это работает».

## Не найдено

- Лицензия блоков как класса: страница цен про коммерческое использование
  молчит; смотреть лицензию у каждого блока на его странице.
- Точный формат адреса реестра (`21st.dev/r/…`) — на странице блока,
  не в документации; проверить при первой установке.
