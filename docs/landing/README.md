# landing — витрина: страница продукта

Дата: 2026-09-22. Витрина завода — публичная страница `/`, которая
продаёт услугу завода: «новость → вертикальный ролик за шесть минут»
(⚖️ landing-sells-service, [journal.md](journal.md)). Каркас снят с
донора по функции, не по теме ([refs.md](refs.md)): у сильных витрин
сервисов один порядок — герой с живыми примерами, «как работает» в три
шага, галерея работ, что внутри, цена, отзывы, вопросы, призыв, футер.

## Блоки

Порядок блоков на странице читается из этого списка (правило зеркала,
как хедер админки из списка «Хедер» в [admin.md](../admin.md)).

1. **Шапка** — имя завода; ссылки «Как работает · Примеры · Цена · Вопросы»; кнопка «Сделать ролик».
2. **Герой** — заголовок «Новость → вертикальный ролик за шесть минут»; три живых ролика из эфира; кнопка «Сделать ролик»; метрика машины: роликов вышло, просмотров за неделю.
3. **Как это работает** — три шага с кадрами: вставьте ссылку на новость → выберите голос → получите ролик и подпись; кнопка.
4. **Примеры** — галерея роликов из «Эфира сети» с просмотрами и досмотром под каждым; живой блок из тех же таблиц, что экран сети.
5. **Что внутри ролика** — четыре карточки: голос рассказчика · карточки с цифрами · цитаты постов · субтитры слово в слово.
6. **Цена** — один тариф на старт, ролик поштучно, с датой; место под подписку.
7. **Отзывы** — «первые заказы», три места; пустой блок не показывается.
8. **Вопросы и ответы** — восемь: сколько ждать, какие новости подходят, чей голос, кому принадлежит ролик, что с чужими кадрами, куда выкладывать, как платить, что если не понравился.
9. **Финальный призыв** — та же кнопка и одна фраза.
10. **Футер** — соцсети завода (площадка коротких видео, Telegram), документы (оферта, персональные данные), почта, ИП и реквизиты.

## Чего у донора не берём

Каталоги шаблонов, тренды, блог, бесплатные инструменты: это витрина
ассортимента, у завода ассортимент один.

## Известные края

- Страница ещё не построена: канон написан до стройки, чтобы стройка шла по нему.
- Цифры героя и галерея — из таблиц завода (`data_raw_instagram_media`, `data_raw_instagram_metrics`); руками не пишутся.
- Кнопка «Сделать ролик» до кассы ведёт на форму заказа без оплаты.
