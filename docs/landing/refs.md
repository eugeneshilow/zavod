# Рефы витрины

Дата: 2026-09-22. Донор каркаса — по функции («кто лучше всех продаёт
услугу ИИ-сервиса одной страницей»), не по теме. В уроках курса донор по
имени не называется — только выводы о блоках (слово владельца 22.09).

## Донор каркаса

- [facee.ru](https://facee.ru/) — ИИ-фотосессии, 2,5 млн клиентов (по их
  метрике на странице 22.09.2026). Снимаем: герой с примерами и одной
  кнопкой; «как создать» в три шага с кадрами; галерея работ
  пользователей; «что ещё умеет» карточками; отзывы с фото; FAQ по
  категориям; финальный призыв с примером; футер с соцсетями,
  документами, почтой поддержки и реквизитами ИП. Не снимаем: каталоги
  шаблонов по темам, тренды, бесплатные инструменты, блог — витрина
  ассортимента.

## Синтез

У сильной витрины сервиса один порядок: обещание с живыми примерами →
три шага → работы → что внутри → цена → отзывы → вопросы → призыв →
футер. Кнопка одна и та же во всех блоках.
