# Рефы витрины

Дата: 2026-09-22. Донор каркаса — по функции («кто лучше всех продаёт
услугу ИИ-сервиса одной страницей»), не по теме. В уроках курса донор по
имени не называется — только выводы о блоках (слово владельца 22.09).

## Донор каркаса

- [facee.ru](https://facee.ru/) — ИИ-фотосессии, 2,5 млн клиентов (по их
  метрике на странице 22.09.2026). Снимаем: герой с примерами и одной
  кнопкой; «как создать» в три шага с кадрами; галерея работ
  пользователей; «что ещё умеет» карточками; отзывы с фото; FAQ по
  категориям; финальный призыв с примером; футер с соцсетями,
  документами, почтой поддержки и реквизитами ИП. Не снимаем: каталоги
  шаблонов по темам, тренды, бесплатные инструменты, блог — витрина
  ассортимента.

## Синтез

У сильной витрины сервиса один порядок: обещание с живыми примерами →
три шага → работы → что внутри → цена → отзывы → вопросы → призыв →
футер. Кнопка одна и та же во всех блоках.

## Набор с Tailark, kit Mist (22.09.2026)

Бесплатный реестр `@tailark-oss` того же автора, что «Content Section» и
«Features 8» выше; полный разбор 96 блоков —
[research/2026-09-22-tailark](research/2026-09-22-tailark/README.md).
Набор из одного kit, чтобы страница была одной рукой; ссылки — живое
превью блока. Синие кнопки Mist → жёлтый завода.

- Проблема: [mist-content-4](https://oss.tailark.com/view/mist-content-4?theme=light) — только верх (заголовок + абзац), три колонки и цифры срезать

- Примеры: [mist-features-2](https://oss.tailark.com/view/mist-features-2?theme=light) — три карточки с картинкой сверху → вертикальные кадры роликов, под каждым просмотры и досмотр

## Набор одной рукой: шапка Preet Suthar + серия LN (22.09.2026, вечер)

Владелец: «Navbar 1 · Preet Suthar — вот это пусть будет шапка; предложи
в консистентном стиле все элементы по странице». Стиль задают два уже
выбранных блока: герой (крупный шрифт, много воздуха, подписи капсом
вразрядку, жёлтый круг) и плавающая шапка-пилюля с чёрной кнопкой.
Правила набора: белый фон везде, без серых лент и тёмных секций; над
каждым заголовком подпись капсом вразрядку, как ссылки в шапке; карточки
скруглённые с тонкой рамкой, без теней (тень только у плавающей шапки);
кнопки чёрные пилюли, как в шапке; жёлтый — только круг героя и одна
плашка отзыва. Автор LN (ln-dev7) держит ровно этот язык во всей серии,
поэтому шесть блоков из девяти — его.

- Шапка: [Navbar 1 · Preet Suthar](https://21st.dev/@preetsuthar17/components/navbar-1) — плавающая пилюля, чёрная кнопка «Сделать ролик»; шапка внутри героя снимается
- Проблема: руками по лекалу LN — подпись капсом, заголовок в две строки, абзац справа; блока «один абзац» на маркетплейсах нет
- Как это работает: [How It Works Steps · LN](https://21st.dev/@ln-dev7/components/how-it-works-01) — три карточки с номерами 01–03, кадр над текстом, чёрная кнопка
- Примеры: [Gallery Grid with Captions · LN](https://21st.dev/@ln-dev7/components/gallery-02) — плитки с подписью и подстрочником → кадры роликов, «просмотры · досмотр»
- Что внутри ролика: [Bento Feature Grid · LN](https://21st.dev/@ln-dev7/components/bento-01) — ровно четыре карточки
- Цена: [Single Plan Pricing Card · LN](https://21st.dev/@ln-dev7/components/pricing-17) — одна карточка, список что входит, чёрная кнопка
- Отзывы: [Staggered Testimonials Grid · Efferd](https://21st.dev/@efferd/components/testimonials-3) — цитаты карточками со сдвигом, тот же язык подписей
- Вопросы и ответы: [Centered Accordion FAQ · LN](https://21st.dev/@ln-dev7/components/faqs-01) — раскрывашки, внизу пилюля «остался вопрос → Telegram»
- Финальный призыв: [Call to Action · Felipe Menezes](https://21st.dev/@felipemenezes098/components/cta-01) — светлая скруглённая плашка, одна фраза, одна чёрная кнопка
- Футер: [Minimal Two-Column Footer · LN](https://21st.dev/@ln-dev7/components/footer-17) — слева имя и реквизиты, справа ссылки; нижняя строка — документы

Набор Mist с Tailark (выше) остаётся запасным: он тоже светлый, но с
серыми лентами и синими кнопками — другая рука.
