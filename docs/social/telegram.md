# telegram — канал через бота: посты и дверь, без цифр

Канон сети. Дверь Telegram публикует тот же материал очереди в канал через Bot API ([publish.md](../publish.md), «Дверь Telegram»). Бот и канал — по одному, переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в Convex.

## Что на экране

- **Посты за семь дней** — строки очереди с дверью `telegram` и статусом «в эфире», по дню публикации.
- **Дверь** — включена или на паузе, с причиной и временем последнего переключения; кнопка паузы.
- **Прогнать очередь сейчас** — тот же тик, что у крона: Instagram, потом Telegram.
- **Подписчики, просмотры, лучшие** — прочерк: Bot API не отдаёт ни подписчиков канала по дням, ни просмотры поста.

## Известные края

- Считать подписчиков можно вызовом `getChatMemberCount` раз в сутки — не сделано; вернётся, когда у канала будет с чем сравнивать.
