# social — соцсети: аккаунты, двери, эфир по дням

Канон зоны: как завод видит свои сети и что в них можно сделать руками. Меняется заменой. Сетей две — [instagram.md](instagram.md) и [telegram.md](telegram.md); файл на сеть — это и есть её экран (`/admin/social/<сеть>`, правило зеркала в [admin.md](../admin.md)).

## Устройство

- **Сеть** — площадка, куда едет материал из очереди публикации ([publish.md](../publish.md)): у неё аккаунт, дверь (тумблер `ops_channel_toggles`) и цифры. Очередь одна на все сети, у каждой сети своя дверь.
- **Сводка `/admin/social`** — карточка на сеть: подписчики, посты за семь дней, просмотры, состояние двери, срок токена; клик — внутрь сети. Ниже эфир по дням: восемь колонок от шести дней назад до завтра, в ячейке число вышедших постов, пунктиром — запланированные. Новая сеть появляется, когда в `docs/social/` ложится её файл: экран сводки читает папку.
- **Экран сети `/admin/social/<сеть>`** — четыре числа (подписчики, просмотры за семь дней, токен, квота за сутки), кнопки руками, лучшие ролики по просмотрам, под ними канон сети.
- **Кнопки руками.** «Поставить дверь на паузу» / «Включить» — событие в `ops_channel_toggles` с причиной. «Прогнать очередь сейчас» — тот же тик, что у крона `instagram-run-queue`, не дожидаясь получаса. «Снять цифры сейчас» — тот же сбор метрик, что у крона раз в шесть часов. Обе кнопки — `services/admin_actions.ts`, за пропуском `ADMIN_API_TOKEN`.

## Откуда цифры

| число                            | откуда                                                      | как часто                            |
| -------------------------------- | ----------------------------------------------------------- | ------------------------------------ |
| подписчики, квота за сутки       | `ops_social_snapshots` (снимок аккаунта)                    | раз в шесть часов кроном или кнопкой |
| посты за семь дней, эфир по дням | `data_cooked_instagram_reels` по `postedAt` и `scheduledAt` | живая очередь                        |
| просмотры, охват, лучшие ролики  | `data_raw_instagram_media` + `data_raw_instagram_metrics`   | раз в шесть часов кроном или кнопкой |
| дверь                            | последнее событие `ops_channel_toggles`                     | мгновенно                            |
| токен и срок                     | `ops_instagram_state`                                       | при обмене кода и продлении          |

Telegram цифр не отдаёт: у канала через Bot API нет подписчиков и просмотров по посту, поэтому у него на экране посты и дверь, остальное — прочерк ([telegram.md](telegram.md)).

## Известные края

- Экран сети с кодом есть только у сетей, чьи данные умеет отдавать база; файл новой сети без кода покажет только канон и прочерки.
- Кнопки «сейчас» ждут ответа Convex до конца тика: прогон очереди с публикацией ролика может идти до минуты.
- Комментарии и ответы людям в админке не живут — это другая машина.
