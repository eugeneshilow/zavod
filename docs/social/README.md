# social — соцсети: аккаунты, двери, эфир по дням

Канон зоны: как завод видит свои сети и что в них можно сделать руками. Меняется заменой. Сетей две — [instagram.md](instagram.md) и [telegram.md](telegram.md); файл на сеть — это и есть её экран (`/admin/social/<сеть>`, правило зеркала в [admin.md](../admin.md)).

## Устройство

- **Сеть** — площадка, куда едет материал из очереди публикации ([publish.md](../publish.md)): у неё аккаунт, дверь (тумблер `ops_channel_toggles`) и цифры. Очередь одна на все сети, у каждой сети своя дверь.
- **Сводка `/admin/social`** — карточка на сеть: подписчики, посты за семь дней, просмотры, состояние двери, срок токена; клик — внутрь сети. Ниже эфир по дням: восемь колонок от шести дней назад до завтра, в ячейке число вышедших постов, пунктиром — запланированные. Новая сеть появляется, когда в `docs/social/` ложится её файл: экран сводки читает папку.
- **Экран сети `/admin/social/<сеть>`** — четыре числа (подписчики, просмотры за семь дней, токен, квота за сутки), кнопки руками, две таблицы и канон сети под ними. Сверху «Идеи» — всё, что ещё не вышло: фаза, история, ролик, цена моделей, кнопки руками. Снизу «Эфир сети» — вышедшее, по просмотрам, с ценой ролика (в хвосте — удалённые с площадки). Ролик вышел — строка переезжает из верхней таблицы в нижнюю.
- **Кнопки руками.** «Поставить дверь на паузу» / «Включить» — событие в `ops_channel_toggles` с причиной. «Опубликовать следующий сейчас» — тот же тик, что у крона `instagram-run-queue`, не дожидаясь получаса: дверь берёт самый старый созревший материал. «Подключить второй аккаунт» — ведёт к порядку обмена кода на токен в каноне публикации. «Снять цифры сейчас» — тот же сбор метрик, что у крона раз в шесть часов. Обе кнопки — `services/admin_actions.ts`, за пропуском `ADMIN_API_TOKEN`.

## Откуда цифры

| число                                   | откуда                                                                            | как часто                                    |
| --------------------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------- |
| подписчики, квота за сутки              | `ops_social_snapshots` (снимок аккаунта `ruvibecoding`)                           | раз в шесть часов кроном или кнопкой         |
| досмотр, длина ролика                   | среднее время просмотра из метрик к `durationMs` очереди (ffprobe при постановке) | вместе с цифрами ролика                      |
| посты за семь дней, эфир по дням        | `data_cooked_instagram_reels` по `postedAt` и `scheduledAt`                       | живая очередь                                |
| просмотры, охват, лучшие ролики         | `data_raw_instagram_media` + `data_raw_instagram_metrics`                         | раз в шесть часов кроном или кнопкой         |
| лайки, комментарии, сохранения, репосты | `data_raw_instagram_metrics` (последний снимок медиа)                             | раз в шесть часов кроном или кнопкой         |
| вовлечённость, средний просмотр         | `data_raw_instagram_metrics`: взаимодействия к охвату и `avgWatchTimeMs`          | раз в шесть часов кроном или кнопкой         |
| удалён с площадки                       | отметка `missingSince` в `data_raw_instagram_media`                               | на сборе цифр, когда медиа пропало из списка |
| идеи, их фазы и цена ролика             | `ops_reel_ideas`                                                                  | кнопкой владельца и раннером на маке         |
| цена ролика                             | токены и `total_cost_usd` из ответа Claude + знаки озвучки на прайс ElevenLabs    | раннером, на каждом шаге работы              |
| дверь                                   | последнее событие `ops_channel_toggles`                                           | мгновенно                                    |
| токен и срок                            | `ops_instagram_state`                                                             | при обмене кода и продлении                  |

Telegram цифр не отдаёт: у канала через Bot API нет подписчиков и просмотров по посту, поэтому у него на экране посты и дверь, остальное — прочерк ([telegram.md](telegram.md)).

## Известные края

- Экран сети с кодом есть только у сетей, чьи данные умеет отдавать база; файл новой сети без кода покажет только канон и прочерки.
- Кнопки «сейчас» ждут ответа Convex до конца тика: прогон очереди с публикацией ролика может идти до минуты.
- Комментарии и ответы людям в админке не живут — это другая машина.
