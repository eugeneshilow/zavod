# explainer — писатель объяснялок

Мозг берёт одну тему про ИИ («как ChatGPT пишет ответ», «что такое
контекст», «почему агент ошибается») и пишет объясняющий ролик для рельсы
[explainers](../../explainers.md): текст голоса по сценам с метками и сами
сцены кодом. Продукт мозга — папка `content/explainers/<id>/` с
`script.json` и `scene.js`; дальше её собирает рендер. Жанр — 3Blue1Brown,
форма снята с ролика Tibo про Shazam
([срез](../../research/explainer-videos-2026-10-03.md)).

## Паспорт

- **семья** — писатели
- **версия** — v1 (2026-10-03)
- **вход** — одна тема про ИИ словами владельца; если есть — для кого ролик и где он выйдет
- **выход** — папка `content/explainers/<id>/`: `script.json` (сцены, текст голоса с метками) и `scene.js` (сцены кодом); 60–80 секунд, 130–150 слов
- **канал** — руками: сессия Claude по брифу владельца; рендер `scripts/explainers/render.mjs`
- **модель** — подписка Claude, главная сессия; пилот `how-chatgpt-writes` написан Opus 5.5
- **след прогона** — `content/explainers`
- **примечание** — пилот «Как ChatGPT пишет ответ» (⚖️ explainer-rail)

## Рецепт

Что мозг читает перед письмом и в каком порядке — [recipe.md](recipe.md).

## Приёмка

- 0 · машина: `tests/explainers.test.ts` держит сценарий, метки и таймлайн; сцена без функции в `scene.js` даёт пустой кадр — его видно на `--stills`.
- 1 · глаза агента: до полной сборки — кадры `--stills` на каждой метке, склейкой в одну картинку; текст не вылезает за край, соседние сцены стыкуются без скачка.
- 2 · уши агента: голос прогоняется распознаванием (`whisper-cli`), сверяется с текстом — нет ли пропусков и слов, которые слышатся двояко («не красивый» → «некрасивый»).
- 3 · смотр владельца: смотрит ролик целиком и говорит «давай» или правит; правки текста копятся и едут одним заходом — каждая переозвучивает весь ролик.
