# brains — мозги завода: роли, которые пишут по рецепту

Мозг — постоянная роль завода, которую исполняет языковая модель по нашей
написанной инструкции. Не человек и не агент-строитель: мозг производит
продукт завода — сценарий ролика, решение, срез. Инструкция мозга — рецепт:
упорядоченный список канонов из `docs/`, которые он читает перед работой,
от общего к частному. Голова мозга — эти каноны, склеенные в один текст.

Три галки, чтобы роль попала сюда: (1) продукт или решение производит
модель; (2) по нашей инструкции, у которой есть версия; (3) как постоянная
роль, а не разовая сессия. Агенты стройки (Claude Code, Codex) — руки, а не
мозги; их правила живут в `AGENTS.md`.

## Как устроен мозг

Один мозг — одна папка `docs/brains/<id>/`, три файла:

- `README.md` — что это за мозг: первая строка `# <id> — <имя>`, раздел
  `## Паспорт` со строками `- **поле** — значение`, раздел `## Приёмка` —
  лестница поверки выхода списком. Поля паспорта: **семья** · **версия** ·
  **вход** · **выход** · **канал** · **модель** · **след прогона** (папка, где
  лежат выходы прогонов) · **примечание** (по желанию).
- `recipe.md` — рецепт: таблица `| канон | секция | зачем |`, первая колонка —
  ссылка на файл в `docs/`, вторая — заголовок раздела (`## История`) или
  `весь файл`, третья — зачем этот канон в голове. Порядок строк = порядок
  работы.
- `journal.md` — дневник мозга: почему рецепт такой, что пробовали и отвергли.

Семьи по тому, что мозг производит: **писатели** (тексты и сценарии) ·
**судьи** (решения) · **разведчики** (срезы и факты) · **собеседники**
(разговоры с людьми) · **мета** (правит правила других мозгов).

## Стекло

Реестр — `/admin/brains`: сводка и таблица по семьям, строка — мозг, клик —
в профиль. Профиль — `/admin/brains/<id>`: паспорт, рецепт по шагам, голова
целиком (собирается из живых файлов рецепта при каждом открытии — протухнуть
ей нечему), приёмка, след прогонов и канон мозга под ними. Мозги читаются
с диска (`lib/brains.ts`): реестра в коде нет — появилась папка с `README.md`
и `recipe.md`, появился мозг в реестре и кнопка в хедере. Адрес экрана =
адрес папки, как у всех зон ([admin.md](../admin.md)).

## Словарь

- **мозг** — постоянная роль завода, которую исполняет модель по рецепту.
- **рецепт** — упорядоченный список канонов, которые мозг читает перед
  работой; живёт в `recipe.md` мозга.
- **голова** — каноны рецепта, склеенные в один текст; видна на профиле.
- **прогон** — один запуск мозга: голова + вводные → продукт.
- **паспорт** — поля мозга в его `README.md`: семья, вход, выход, канал.
