## Вводные прогона

Бриф владельца: ссылка на новость и, если есть, кадр источника. Образец
готового выхода — `content/reels/stories/robot-knife.json`: шестнадцать
битов, у каждого `text` для экрана, `say` для голоса с тегом и `visual` —
видео с кропом, карточка с цифрой или карточка поста.

## Порядок работы

1. Прочитать рецепт целиком в порядке таблицы.
2. Из новости вынуть героя, ситуацию и механику «почему так»; найти поворот.
3. Написать биты: первая фраза — герой и ситуация, по одному факту на бит,
   поворот в середине, финал — последствие или ирония. Считать слова:
   больше 110 — резать текст, не темп.
4. К каждому биту — кадр: видео или картинка источника с лицензией, карточка
   с цифрой, карточка поста. Файл без строки в `LICENSES.md` не брать.
5. Разметить голос в `say`: числа и латиница словами, не больше одного тега
   на бит, теги только из списка ElevenLabs.
6. Отдать файл рендеру, прочитать отчёт: длительность, слова в минуту, паузы.
