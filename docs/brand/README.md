# brand — бренд-атлас: как завод выглядит снаружи

Дата: 2026-09-22. Зона бренда — атлас: всё, по чему завод узнают и по чему
строятся его поверхности. Правило одно на зону: **число живёт в каноне,
код его переносит** (Spec-Driven, как у витрины и админки). У каждого
канона зоны ровно один переносчик в коде, один экран в админке по правилу
зеркала ([admin.md](../admin.md)) и один тест-поверка.

## Атлас

Экран `/admin/brand` — бренд-атлас во весь экран, форма снята с атласа
vibecoding.ru: живая страница в раме атласа и плавающий пульт справа
снизу. Пульт: **вид** — «главная» (витрина `/`) или «полигон лого»;
**разрез** главной — «чистый» или «гриды» (три оси из [layout.md](layout.md));
**экран** — 375 · 768 · 1280 · во всю. Состояние живёт в адресе, ссылку на
нужный вид можно отправить в чат. Рама админки на атласе выключена
(`app/admin/_components/frame.tsx`).

Каноны зоны и их стёкла по правилу зеркала:

| Канон                  | Стекло                                                | Переносчик                                   |
| ---------------------- | ----------------------------------------------------- | -------------------------------------------- |
| [layout.md](layout.md) | атлас, разрез «гриды» · `/admin/brand/layout` (числа) | `lib/layout.ts` · накладка `/?grid`          |
| [logo.md](logo.md)     | `/admin/brand/logo`                                   | `lib/brand.ts` · `components/brand/logo.tsx` |
| [lab.md](lab.md)       | атлас, вид «полигон лого» · `/admin/brand/lab`        | `lib/brand-lab.ts`                           |

Новый вид атласа — файл канона здесь и строка в списке видов
`app/admin/brand/atlas.tsx`.

## Что здесь

- [layout.md](layout.md) — сетка витрины: полоса 1152, двенадцать колонок,
  ритм секций, два исключения (шапка и герой).
- [logo.md](logo.md) — логотип: знак «z» в жёлтом круге и слово «zavod»;
  числа знака, написание, охранное поле, где стоит; favicon `app/icon.svg`.
- [lab.md](lab.md) — полигон: двенадцать разных пар знак + слово для выбора глазами;
  переносчик — `lib/brand-lab.ts`, стекло — `/admin/brand/lab`.
- [journal.md](journal.md) — почему так решили, что отвергли.

## Чего здесь пока нет

Палитра и шрифт живут в коде витрины (`app/globals.css`: один шрифт Inter,
жёлтый `#F5B700`). Их каноны и режимы атласа появятся, когда у них будет
второе место применения кроме витрины: правило семи, сущность заводится по
нужде, не впрок.
