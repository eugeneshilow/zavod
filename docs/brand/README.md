# brand — бренд: как завод выглядит снаружи

Дата: 2026-09-22. Зона бренда — всё, по чему завод узнают: знак, слово,
цвет. Правило одно на зону: **число живёт в каноне, код его переносит**
(Spec-Driven, как у витрины и админки). У каждого канона зоны ровно один
переносчик в коде и один экран в админке по правилу зеркала
([admin.md](../admin.md)).

## Что здесь

- [logo.md](logo.md) — логотип: знак «z» в жёлтом круге и слово «zavod»;
  числа знака, написание, охранное поле, где стоит. Переносчик —
  `lib/brand.ts`, компонент — `components/brand/logo.tsx`, favicon —
  `app/icon.svg`, стекло — `/admin/brand/logo`, поверка — `tests/brand.test.ts`.
- [journal.md](journal.md) — почему знак такой, что отвергли.

## Чего здесь пока нет

Палитра и шрифт живут в коде витрины (`app/globals.css`: один шрифт Inter,
жёлтый `#F5B700`). Канон цвета и типографики появится, когда у них будет
второе место применения кроме витрины: правило семи, сущность заводится по
нужде, не впрок.
