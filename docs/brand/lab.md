# lab — полигон логотипов: варианты на выбор

Дата: 2026-09-22. Экран — `/admin/brand/lab`, переносчик —
`lib/brand-lab.ts`, поверка — `tests/brand-lab.test.ts`.

## Простая история

Завод превращает новость в вертикальный ролик за шесть минут: собирает
голос, карточки, цитаты и субтитры, затем выпускает ролик по расписанию.
Полигон показывает двенадцать разных способов выразить эту работу знаком.
Владелец выбирает глазами: смотрит на пару из знака и длинного логотипа,
затем на знак в 16 px. Это выбор направления; действующий логотип живёт
по своему [канону](logo.md), до отдельного решения его не заменяют.

Каркас сравнения взят с существующего экрана `/admin/brand/logo`: одинаковые
фоны и размеры помогают сравнивать форму. Каждый вариант получает свою
карточку с мыслью, длинной формой на белом и чёрном, знаками в 16, 32, 64 и
128 px, чёрным знаком и чёрной длинной формой на белом. Формы нарисованы
для этого задания геометрией; готовые чужие знаки за образец не берутся.

## Устройство пары

Знак — SVG в квадрате 1024 × 1024, только геометрия, без текста и шрифтов.
Геометрия каждого знака занимает высоту от 128 до 896 юнитов: силуэты в
парах сравниваются в одинаковом масштабе. Все пути и координаты живут в
переносчике, отдельных файлов картинок нет.

Длинная форма — знак слева, `zavod` справа одной строкой. Общие числа всех
пар закреплены константой `LAB_LOCKUP` в переносчике:

| Что                            | Значение    |
| ------------------------------ | ----------- |
| Кегль слова, юниты             | 128         |
| Сторона квадрата знака, кеглей | 1,25        |
| Зазор после квадрата, кеглей   | 0,25        |
| Разрядка слова, em             | 0,05        |
| Вес Inter                      | 700         |
| viewBox длинной формы          | 0 0 640 160 |

Единственный цвет — жёлтый `#F5B700`; остальные — чёрный `#000000` и
белый `#FFFFFF`. Цветной знак сохраняется на обоих фонах; слово берёт
чёрный или белый цвет поверхности. Одноцветная пара — чёрная на белом.
В SVG слово набрано Inter с запасным системным шрифтом; на экране оно
использует уже подключённый Inter. Контуры слова для лаборатории не нужны.

## Как выбирают

1. **Читается в 16 px.** Силуэт и главная прорезь различимы в размере
   закладки браузера без увеличения страницы.
2. **Живёт без жёлтого.** В чёрной версии сохраняются мысль и отличие от
   соседних вариантов; цвет не спасает слабую форму.
3. **Не путается с чужими знаками.** После визуального отбора владелец
   проверяет короткий список на сходство; полигон сам по себе не
   подтверждает уникальность.

Выбор фиксируют по `id` и паре целиком. Перерисовка победителя и замена
логотипа на рабочих поверхностях — отдельный шаг после выбора владельца.

## Порядок сборки и приёмка

Сначала фиксируются этот канон и список идей, затем переносчик с геометрией,
после него серверный экран и поверка. Приёмка: 10–12 вариантов, минимум
семь семейств, таблица совпадает с переносчиком, `pnpm check` и `pnpm build`
зелёные, `/admin/brand/lab` отвечает 200, полный скриншот просмотрен:
карточки вмещают знаки, в 16 px различимы главные формы.

## Не делать

- Не брать букву «z» за основу ни одного знака.
- Не превращать полигон в двенадцать перестановок одной формы.
- Не добавлять цвета, градиенты, тени, декоративные обводки, эмодзи и стоковые иконки.
- Не вставлять текст и шрифты в квадратный знак.
- Не растягивать пары, не менять масштаб знака между вариантами.
- Не заменять действующий знак, favicon, шапку и футер выбором агента.

## Словарь

- **полигон** — экран для сравнения направлений логотипа до выбора владельца.
- **вариант** — одна идея со своим id, семейством и геометрией.
- **пара** — квадратный знак и горизонтальный логотип из того же знака со словом.
