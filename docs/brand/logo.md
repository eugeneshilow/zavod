# logo — знак «z» в жёлтом круге и слово «zavod»

Дата: 2026-09-22 (⚖️ logo-yellow-z, [journal.md](journal.md)). Канон
логотипа: одно место, где живут его числа. Код исполняет: переносчик
`lib/brand.ts`, компонент `components/brand/logo.tsx`, favicon `app/icon.svg`;
экран `/admin/brand/logo` показывает знак во всех размерах и сверяет favicon
с переносчиком; тест `tests/brand.test.ts` валит сборку, если числа здесь и в
коде разошлись.

## Простая история

У завода один цвет, который зритель уже видел: жёлтый круг героя витрины с
кадром ролика внутри. Знак — тот же круг, только вместо кадра в нём буква
«z». Буква не из шрифта, а из трёх штрихов: верхний, диагональ, нижний.
Так знак одинаков везде — на странице, в закладке браузера, в аватарке
площадки — и не зависит от того, загрузился ли шрифт. Слово «zavod» стоит
рядом строчными, жирным Inter, с той же разрядкой, что и ссылки шапки.

## Две формы

- **Знак** — жёлтый круг, чёрная «z». Одноцветный вариант для печати и
  мест без жёлтого: чёрный круг, белая «z».
- **Знак и слово** — знак слева, слово справа одной строкой. Слово берёт
  цвет текста вокруг: на светлом чёрное, на тёмном белое; знак остаётся
  жёлтым.

## Числа знака

Квадрат знака — 1024 юнита; буква вписана в центр.

| Что                                   | Юниты |
| ------------------------------------- | ----- |
| Сторона квадрата                      | 1024  |
| Буква: левый край                     | 296   |
| Буква: правый край                    | 728   |
| Буква: верх                           | 296   |
| Буква: низ                            | 728   |
| Толщина горизонтальных штрихов        | 96    |
| Сдвиг кромок диагонали по горизонтали | 152   |

Диагональ идёт из правого верха в левый низ; сдвиг 152 даёт ей толщину,
на глаз равную штрихам.

## Написание рядом со знаком

Кегль слова задаёт всё остальное.

| Что                            | Значение           |
| ------------------------------ | ------------------ |
| Диаметр знака                  | 1,25 кегля слова   |
| Зазор знак — слово             | 0,45 кегля слова   |
| Разрядка слова                 | 0,05 em            |
| Шрифт                          | Inter, вес 700     |
| Охранное поле с каждой стороны | 0,5 диаметра знака |
| Минимум: знак                  | 16 px              |
| Минимум: слово                 | 12 px              |

## Где стоит

- Шапка витрины `/` — знак и слово, кегль 18.
- Футер витрины — знак и слово, кегль 18.
- Хедер админки `/admin` — знак и слово, кегль 14, на чёрной полосе.
- Закладка браузера — знак, файл `app/icon.svg`.

## Не делать

- Не растягивать, не поворачивать, не менять цвет круга.
- Не ставить слово без разрядки и не набирать его заглавными.
- Не класть знак на жёлтый фон: круг сливается; на жёлтом — одноцветный.
- Не рисовать «z» шрифтом: буква — только из штрихов переносчика.

## Словарь

- **знак** — жёлтый круг с чёрной «z»; одноцветный — чёрный круг с белой «z».
- **знак и слово** — знак и «zavod» одной строкой, доли кегля из таблицы.
- **охранное поле** — пустое место вокруг логотипа, доля диаметра знака.
- **переносчик** — `lib/brand.ts`, единственный код, который знает числа этого канона.
