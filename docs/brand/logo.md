# logo — лента-стрелка и надпись «zavod.today»

Дата: 2026-09-23 (⚖️ logo-ribbon-teal, [journal.md](journal.md)). Канон
логотипа: набор файлов, который принёс владелец 22.09.2026, и правила его
применения. Код исполняет: переносчик `lib/brand.ts` (реестр файлов,
палитра, кнопки скачивания, правила), компонент `components/brand/logo.tsx`,
закладка `app/icon.svg` и `app/favicon.ico` как копии файлов набора; вид
«лого» бренд-атласа `/admin/brand/logo` показывает логотип, отдаёт файлы под
площадки и сверяет закладку с набором; тест `tests/brand.test.ts` валит
сборку, если файл реестра пропал с диска, таблица здесь разошлась с
реестром или закладка отстала от набора.

## Простая история

Знак — бирюзовая лента, сложенная стрелкой «пуск», рядом наклонная надпись
«zavod.today». Владелец нагенерил его отдельно и принёс готовым набором:
векторные контуры без шрифтов, растровые копии, аватары под площадки и
закладки браузера. Завод набор не перерисовывает, а хранит как есть в
`public/brand/logo/` и раздаёт с одного экрана: у каждой площадки своя
кнопка «скачать», у каждой поверхности сайта — свой файл из реестра.
Прежний знак с буквой «z» снят.

## Формы

- **Полный логотип** — лента и надпись одной строкой; primary на светлом,
  inverse на тёмном, black и white одноцветные.
- **Знак** — лента без надписи; primary и inverse.
- **Квадратный аватар** — знак на бирюзовом со скруглением, на петрольном,
  без скруглений для системной маски, чёрный.
- **Закладка** — одноцветная лента на петрольном; читается в 16 px.

## Где стоит

- Шапка витрины `/` — полный логотип primary, высота 54 (ширина 182, минимум набора).
- Футер витрины — полный логотип primary, высота 54.
- Хедер админки — полный логотип inverse, высота 24, на чёрной полосе: служебная
  поверхность, единственное место ниже минимума набора.
- Закладка браузера — `app/icon.svg` и `app/favicon.ico`, копии файлов
  набора; иконка домашнего экрана — `app/apple-icon.png`.
- Площадки — вид «лого» атласа, кнопки «скачать» по площадкам.

## Правила

| Что                                   | Значение          |
| ------------------------------------- | ----------------- |
| Минимум полного логотипа, px          | 180               |
| Минимум отдельного цветного знака, px | 32                |
| Свободное поле вокруг знака           | 0,25 высоты знака |

- Сохранять пропорции; не добавлять тени и обводки.
- В полном логотипе не менять расстояние между знаком и надписью.
- На тёмном — только inverse или white; тёмную надпись на тёмном не ставить.
- Для 16–32 px брать готовую закладку, не уменьшать цветной знак.
- SVG — источник; PNG — для сервисов без SVG.

## Словарь

- **полный логотип** — лента и надпись одной строкой.
- **знак** — лента без надписи.
- **аватар** — квадратный файл под профиль площадки, с полями набора.
- **закладка** — favicon: одноцветная лента на петрольном.
- **реестр** — список файлов набора в переносчике; таблица «Файлы» повторяет его по id.
