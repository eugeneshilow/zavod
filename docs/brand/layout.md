# layout — сетка витрины: полоса, колонки, ритм

Дата: 2026-09-22 (⚖️ landing-band-1152, [journal.md](journal.md)). Канон
раскладки страницы `/`: одно место, где живут её числа. Код исполняет:
переносчик `lib/layout.ts` (классы полосы и секции, числа), блоки витрины
берут классы из него; накладка `components/brand/grid-overlay.tsx` рисует
сетку поверх живой страницы по адресу `/?grid`; режим «лендинг» бренд-атласа
`/admin/brand/layout` показывает схему и числа; тест `tests/layout.test.ts`
валит сборку, если числа здесь и в коде разошлись или блок набрал полосу
руками.

## Простая история

Витрина собрана из одиннадцати блоков, и почти все они стоят на одной
полосе: 1152 px по центру экрана, с полями по краям. Внутри полосы
двенадцать колонок с зазором 24 px: заголовок «проблемы» занимает шесть
колонок, футер делится как шесть, три и три. Между секциями один и тот же
воздух сверху и снизу. Два блока живут иначе, и это записано, а не
случилось: шапка-пилюля уже полосы, герой шире и во весь экран, потому что
так задумано у их доноров.

## Полоса и колонки

| Что                       | Значение | Tailwind       |
| ------------------------- | -------- | -------------- |
| Полоса контента, px       | 1152     | `max-w-6xl`    |
| Поля на мобиле, px        | 24       | `px-6`         |
| Поля от md, px            | 40       | `md:px-10`     |
| Колонок                   | 12       | `grid-cols-12` |
| Зазор между колонками, px | 24       | `gap-6`        |
| Ритм секций на мобиле, px | 80       | `py-20`        |
| Ритм секций от md, px     | 112      | `md:py-28`     |

Ширина одной колонки на десктопе — 67 px: полоса минус поля, минус
одиннадцать зазоров, делить на двенадцать.

## Исключения

| Что                       | Значение | Tailwind    |
| ------------------------- | -------- | ----------- |
| Шапка: полоса, px         | 1024     | `max-w-5xl` |
| Шапка: отступ сверху, px  | 16       | `top-4`     |
| Шапка: высота пилюли, px  | 56       | `py-2`      |
| Герой: полоса, px         | 1280     | `max-w-7xl` |
| Герой: поля на мобиле, px | 32       | `p-8`       |
| Герой: поля от md, px     | 48       | `md:p-12`   |

Шапка плавает над страницей и не привязана к полосе контента; герой занимает
экран целиком и держит три колонки на своей полосе. Третьего исключения нет:
новый блок встаёт на полосу 1152 классом из переносчика.

## Оси накладки

Линий три, больше не рисуем (слово владельца 22.09): две вертикальные по
внутренним краям полосы контента и одна горизонтальная по низу шапки.

| Ось | Что                           | Где на экране 1440, px |
| --- | ----------------------------- | ---------------------- |
| V1  | левый внутренний край полосы  | 184                    |
| V2  | правый внутренний край полосы | 1256                   |
| H1  | низ шапки-пилюли              | 72                     |

V1 и V2 считаются от полосы и полей: (экран − 1152) / 2 + 40; H1 — отступ
шапки сверху плюс её высота. Смотреть: `/admin/brand` — бренд-атлас, вид
«главная», разрез «гриды»; то же на самой витрине по адресу `/?grid`.

## Не делать

- Не писать полосу или ритм секции строкой классов в блоке: только
  `BAND_CLASS` и `SECTION_CLASS` из переносчика.
- Не заводить третью полосу: нужна другая ширина — сначала строка здесь.
- Не рисовать в накладке чисел, которых нет в переносчике, и линий сверх трёх осей.

## Словарь

- **полоса** — колонка контента по центру экрана; у витрины одна, 1152 px.
- **поля** — отступ от края экрана до полосы на узких экранах.
- **колонки** — двенадцать долей полосы с зазорами; блок делит их между частями.
- **ритм секций** — одинаковый отступ сверху и снизу у каждой секции.
- **накладка** — сетка поверх живой страницы по адресу с параметром `grid`.
