# layout — сетка витрины: полоса, колонки, ритм

Дата: 2026-09-23 (⚖️ landing-band-1376, [journal.md](journal.md)). Канон
раскладки страницы `/`: одно место, где живут её числа. Код исполняет:
переносчик `lib/layout.ts` (классы полосы и секции, числа), блоки витрины
берут классы из него; накладка `components/brand/grid-overlay.tsx` рисует
оси поверх живой страницы по адресу `/?grid`; бренд-атлас `/admin/brand`
показывает её в разрезе «гриды», числа — на `/admin/brand/layout`; тест
`tests/layout.test.ts` валит сборку, если числа здесь и в коде разошлись или
блок набрал полосу руками.

## Простая история

Витрина собрана из одиннадцати блоков, и все они стоят на одной полосе:
1376 px по центру экрана, с полями по краям, внутри полей ровно 1280. Полосу задал герой: его
абзац слева и заголовок справа — и есть края, по которым выровнены шапка,
футер и остальные блоки (слово владельца 22.09: «поставь V1 V2 пошире по
границам героя и по ним выровняй остальные элементы, включая хедер и
футер»). Внутри полосы двенадцать колонок с зазором 24 px: заголовок
«проблемы» занимает шесть колонок, футер делится как шесть, три и три.
Между секциями один и тот же воздух сверху и снизу. Исключение одно:
шапка-пилюля плавает над страницей, но её края стоят на той же полосе.

## Полоса и колонки

| Что                       | Значение | Tailwind         |
| ------------------------- | -------- | ---------------- |
| Полоса с полями, px       | 1376     | `max-w-[1376px]` |
| Поля на мобиле, px        | 32       | `px-8`           |
| Поля от md, px            | 48       | `md:px-12`       |
| Колонок                   | 12       | `grid-cols-12`   |
| Зазор между колонками, px | 24       | `gap-6`          |
| Ритм секций на мобиле, px | 80       | `py-20`          |
| Ритм секций от md, px     | 112      | `md:py-28`       |

Ширина одной колонки на десктопе — 85 px: полоса минус поля, минус
одиннадцать зазоров, делить на двенадцать.

## Шапка

| Что                      | Значение | Tailwind |
| ------------------------ | -------- | -------- |
| Шапка: отступ сверху, px | 16       | `top-4`  |
| Шапка: высота пилюли, px | 56       | `py-2`   |

Пилюля плавает над страницей и занимает всю полосу: её левый край на V1,
правый на V2. Герой стоит на той же полосе во весь экран. Второй полосы
нет: новый блок встаёт на полосу классом из переносчика.

## Оси накладки

Линий три, больше не рисуем (слово владельца 22.09): две вертикальные по
внутренним краям полосы и одна горизонтальная по низу шапки.

| Ось | Что                           | Где на экране 1440, px |
| --- | ----------------------------- | ---------------------- |
| V1  | левый внутренний край полосы  | 80                     |
| V2  | правый внутренний край полосы | 1360                   |
| H1  | низ шапки-пилюли              | 72                     |

V1 и V2 считаются от полосы и полей: (экран − 1376) / 2 + 48; H1 — отступ
шапки сверху плюс её высота.

Рисуется как в накладке атласа vibecoding.ru: оси контента V1 и V2 —
оранжевые, ось рамы H1 — зелёная; бирка с id стоит прямо на линии, при
наведении на ось у курсора всплывает её имя и число, слева внизу плашка с
шириной окна и положением осей. Этими именами ось называют в чате: «сдвинь
заголовок к V2».

## Не делать

- Не писать полосу или ритм секции строкой классов в блоке: только
  `BAND_CLASS` и `SECTION_CLASS` из переносчика; шапка — `NAVBAR_BAND_CLASS`.
- Не заводить вторую полосу: нужна другая ширина — сначала строка здесь.
- Не рисовать в накладке чисел, которых нет в переносчике, и линий сверх
  трёх осей.

## Словарь

- **полоса** — колонка контента по центру экрана; у витрины одна, 1376 px с
  полями и 1280 внутри, по краям героя.
- **поля** — отступ от края экрана до полосы на узких экранах.
- **колонки** — двенадцать долей полосы с зазорами; блок делит их между частями.
- **ритм секций** — одинаковый отступ сверху и снизу у каждой секции.
- **накладка** — оси поверх живой страницы по адресу с параметром `grid`.
