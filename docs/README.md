# zavod

Одна страница. Что это за проект, что решено, где что лежит. Держите её на одной странице: если она растёт, что-то под ней хочет свою папку.

## Что это

zavod — заготовка проекта, собранная как Spec-Driven Company: истина живёт в `docs/`, агенты её исполняют, статус виден на странице, а не в чате. Веб-приложение на Next.js: главная называет проект и ведёт на `/admin`; `/admin` — executive summary завода, а под ним по экрану на зону, адрес экрана = адрес канона в `docs/` ([admin.md](admin.md)). Проект живёт онлайн: открытый репозиторий на GitHub, хостинг Vercel, база Convex в облаке.

«Работает» значит: `pnpm check` зелёная; http://localhost:3000 отвечает страницей проекта; репозиторий существует и `main` запушен; адрес продакшена отвечает 200, его `/admin` с паролем показывает журнал с двумя решениями.

## Решения

Решения живут в [journal.md](journal.md), новые сверху, у каждого постоянное имя. Те, что определяют всё остальное:

- ⚖️ adopt-spec-driven-company — истина живёт в docs, агенты исполняют, статус виден.
- ⚖️ go-online-github-vercel-convex — проект живёт онлайн: GitHub, Vercel, Convex в облаке; с 20.09 репозиторий открытый (⚖️ public-zavod).
- ⚖️ reels-straight-to-instagram — ролики и картинки едут в Instagram сами: очередь, крон, метрики, пауза кнопкой.
- ⚖️ telegram-door — у той же очереди вторая дверь: тот же ролик едет ещё и в канал Telegram, тумблер у каждой двери свой.
- ⚖️ second-instagram-account — аккаунтов Instagram два: `ruvibecoding` (по умолчанию) и `autovibecoding`; токен каждого машина получает в обмен на код входа.

## Где что лежит

- `docs/` — истина: эта страница, журнал, по файлу на зону; `docs/brains/` — мозги, по папке на каждый.
- `AGENTS.md` — правила, которые каждый агент читает первыми. Его раздел «Стек» говорит, из чего сделан проект, как его проверить и как запустить.
- `app/` — страницы Next.js (App Router): `/`, `/admin` и экраны зон `/admin/<зона>`; рама админки — `app/admin/_components/`. `lib/` — чтение docs (дерево зон, каноны, решения), результат проверки, мост к рельсе публикации. `convex/` — схема и серверные функции Convex. `tests/` — тесты Vitest. `scripts/check.mjs` — одна команда проверки.
- `content/reels/` — входы рельсы роликов: лекало слайда и по файлу на серию, на плакат и на историю; `content/reels/media/` — картинки и видео историй с их лицензиями. `scripts/reels/` — рендер: Playwright снимает кадры, ffmpeg собирает файл. `assets/music/` — треки для вшивания и их лицензии. Готовые ролики ложатся в `out/`, он вне git.
- `.github/workflows/` — проверка на pull request и почасовой сторож продакшена; `vercel.json` — команда сборки Vercel.
- `convex/` — схема, таблицы, сервисы и кроны рельсы публикации; `scripts/reels/publish.mjs` — залить ролик и поставить в очередь.
- `.env.local` — файл с ключами, никогда не коммитится. Имена переменных — в `.env.local.example`.

## Зоны

По файлу на зону проекта, каждый — канон того, как эта зона устроена прямо сейчас.

- [admin.md](admin.md) — админка: вход `/admin`, хедер из списка в каноне (brains, social), правило зеркала «адрес экрана = адрес канона».
- [deploy.md](deploy.md) — выход наружу: репозиторий, проверка, Vercel, Convex, ключи, откат.
- [reels.md](reels.md) — сборка вертикальных роликов: серия слайдов и плакат из одной картинки, тайминг, музыка, требования Instagram к файлу.
- [publish.md](publish.md) — публикация: одна очередь роликов и картинок, две двери (Instagram и Telegram), гейты, повтор после сбоя, эфир и метрики.
- [social/](social/README.md) — соцсети: по файлу на сеть, экран сводки `/admin/social` с эфиром по дням и экран сети с кнопками; первые две — Instagram и Telegram.
- [landing/](landing/README.md) — витрина: страница `/`, продаёт услугу «новость → ролик»; десять блоков списком, порядок на странице — из списка.
- [brains/](brains/README.md) — мозги: роли, которые пишут по рецепту из канонов; по папке на мозг с паспортом, рецептом и журналом; первый — писатель коротких роликов.

## Статус

Где виден живой статус: `/admin/social` (за паролем) — сети, двери, эфир по дням; `/admin/social/<сеть>` — цифры и кнопки одной сети; очередь целиком — `/admin/publish`; мозги — `/admin/brains`. Docs описывают, как всё устроено; текущих чисел они никогда не держат.
