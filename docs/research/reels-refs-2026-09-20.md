## Что общего у сильных рефов

- **Один образ на ролик.** Ни в одном рефе нет монтажа из сцен: кадр
  один (1, 4), серия одного лекала (2, 5) или один график, который
  движется (3, 6).
- **Текст — часть картинки, не субтитры.** Имена оттенков (5), название
  бренда на предмете (2), подписи графика (3, 6). Голоса нет нигде.
- **Данные и списки собирают комментарии.** «Свой» оттенок (5), спор о
  цифрах (3): зритель дописывает ролик сам.
- **Машине доступны 3, 5 и 6 целиком**: график или список из данных
  рисуется кодом; 1 и 4 — ручной вкус фотографа и художника, машина
  повторит только картинкой из генератора; 2 — нужен продукт-предмет.

## Гипотезы форматов для vibecoding.tech (проверяются просмотрами)

| # | Формат | Реф-донор | Из чего делает машина | Гипотеза |
|---|---|---|---|---|
| Г1 | **Данные в движении**: график «модель × месяц», «доля внимания агентов», «цена за миллион токенов» — одна ось времени, одна цифра в заголовке | 3, 6 | таблица данных → кадры кодом (HTML-слайд на каждый шаг времени → скриншот → склейка) | у ИИ-рынка нет своего «randomdatavstime»; данные меняются каждую неделю — бесконечный источник тем |
| Г2 | **Именованный список**: «десять агентов для кода, от дешёвого к дорогому», «что значат имена моделей», «семь слов из отчёта агента» | 5 | список из базы идей → слайды типографикой, один цвет на серию | списки собирают комментарии «мой — третий»; делается без картинок вообще |
| Г3 | **Плакат + одна строка**: картинка-аллегория из генератора (стиль как у обложек уроков) и одна фраза про машину, которая строит софт | 1, 4 | сюжет → картинка по подписке (без API видео) → одна строка текстом на кадре | настроение цепляет шире ниши; дешёвый ролик на каждый день между сериями |
| Г4 | **Продукт как предмет**: экраны нашей же машины (админка, журнал решений, зелёная проверка) как «вещь дня» | 2 | скриншот машины по расписанию → рамка и подпись | «стройка на людях»: сама машина — источник тем; проверяет, интересно ли смотреть на софт как на предмет |

Порядок проверки: Г2 первой (самая дешёвая, полностью из текста),
затем Г1 (самая узнаваемая, нужен слой данных), Г3 и Г4 — по одному
ролику в неделю как контраст. Мера — просмотры и сохранения за 48
часов против медианы аккаунта; две недели на формат, не меньше десяти
роликов, потом сдвиг микса (правило меню из канона коротких видео).

## Музыка и звук (подробно — [music-and-formats-2026-09-20.md](music-and-formats-2026-09-20.md))

- С мая 2026 трек из библиотеки Instagram можно прикрепить при
  публикации через API (`audio_configuration` с `audio_id`), но только в
  ветке с входом через Facebook: нужна связанная страница Facebook.
- Музыку из библиотеки Meta вшивать в файл нельзя: лицензия только для
  продуктов Meta. Вшивать можно royalty-free (Pixabay — бесплатно, без
  указания автора) или сгенерированную (Suno Pro $8/мес даёт
  коммерческие права на дату проверки).
- Решение для v1: музыка вшивается в файл из Pixabay (одна папка треков
  под серию, машина выбирает по кругу); v2 — трек из библиотеки через
  API, когда подключим страницу Facebook. Ролик без звука не выкладываем.
