# Промо-ролик из страницы сайта: как Claude Code делает «вау»

Дата: 2026-10-12. Пасс из двух разведчиков (opus-5.5): интернет в целом и
X. Вопрос владельца: «как ты, Claude Code, можешь сделать вау-ролик из
страницы https://vibecoding.tech/services?»

## Ответ одной строкой

Ставим открытый HyperFrames от HeyGen, даём ему адрес страницы. Он снимает
страницу, пишет раскадровку и текст голоса на одобрение и собирает MP4.
Движущиеся куски (очередь задач, Slack-тред, счётчик, цены) пересобираем
кодом поверх снимков. Голос и музыку берём свои, из ElevenLabs.

## Что нашли

- **HyperFrames** ([репо](https://github.com/heygen-com/hyperframes),
  60 958 звёзд, Apache-2.0 без порогов, проверено через GitHub API
  2026-10-12) — HTML → видео, «Built for agents». Плагин для Claude Code
  и навык `/product-launch-video`: «дай адрес — получи промо», сам
  снимает сайт (`npx hyperframes capture <URL>`), берёт цвета и шрифты,
  по сабагенту на сцену. В навык зашит вкус моушн-дизайна: плавно, без
  отскоков; появление под голос во второй половине сцены; склейки по
  скорости. Исходники 20 роликов-запусков самой HeyGen —
  [hyperframes-launches](https://github.com/heygen-com/hyperframes-launches).
- **Remotion + Claude Code** — путь с самым большим охватом в X
  ([анонс навыков](https://x.com/Remotion/status/2013626968386765291),
  18,9 млн просмотров; на деле 31 промпт на 8 секунд). Сильнее всего,
  когда оживляют настоящие компоненты продукта, а не рисуют интерфейс
  заново. Для компании до трёх человек бесплатно. Наш завод 03.10 его
  отверг для объяснялок (⚖️ explainer-rail) — довод «тяжело» в силе.
- **Claude Motion** (Anthropic, бета с 08.10.2026, только Team и
  Enterprise) — «отчёт или прогулка по продукту → анимация кодом → MP4»
  ([пост](https://x.com/claudeai/status/2108271558170976743), проверен
  2026-10-12). На нашей подписке недоступен.
- **Готовый промпт «сайт → ролик за 30 с»** —
  [RoundtableSpace, 11.10.2026](https://x.com/RoundtableSpace/status/2109203601902174297)
  (проверен 2026-10-12): логотип 0–3 с → заголовок по слову 3–8 →
  по сцене на фичу с настоящими скриншотами 8–23 → призыв 23–30;
  «Show me 3 still frames for approval, then render».
- **Запись живой страницы** (Playwright, курсор, наезды) — только как
  вставка внутрь ролика. Screen Studio и аналоги агентом не водятся.
- **Генеративное видео** (Veo и др.) — максимум 2–3 секунды в начале;
  интерфейс, цифры и цены моделями не рисовать — коверкают текст.
- **Главная ошибка** у всех: без образца выходит «centered text, gradient
  background, everything fading in». Лечение — образец-ролик вместо
  описания стиля, настоящие снимки или компоненты, сначала голос, потом
  картинка, отдельный проход критика по секундам.

## Раскадровка для /services (черновик, 30 с)

| с | что на экране | откуда на странице |
| --- | --- | --- |
| 0–3 | в Slack печатается задача «Need a landing page. Launch on Friday», звук клавиш | карточки сценариев |
| 3–8 | «Agentic engineering» по слову; «One monthly price instead of hiring a team» | герой |
| 8–20 | карточки очереди становятся Done одна за другой; тред «сайт упал» → «починили»; три шага «48 часов» | сценарии, процесс |
| 20–25 | счётчик «86 tasks shipped a week» растёт; стопка «13 people» схлопывается в одного инженера с агентами | цифры |
| 25–30 | две карточки цен; курсор жмёт «Book a call»; адрес | цены, шапка |

Две версии: 1920×1080 для сайта и YouTube, 1080×1920 для X и Reels.
Голос — около 65–70 английских слов, музыка ниже −18 дБ.

## Рейтинг путей

1. HyperFrames `/product-launch-video` по адресу + живые вставки кодом.
2. Remotion со своими компонентами страницы — если первый выйдет шаблонным.
3. Запись страницы — только слоем внутри 1 или 2.
4. Наш холст объяснялок ([explainers.md](../../explainers.md)) — если
   остаёмся на своём стеке; интерфейс придётся рисовать заново.
5. Генерация — только холодное открытие.

  ни у кого — как анимировать таблицу и FAQ, никто не показал.
