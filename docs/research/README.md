# research — датированные срезы

Здесь лежат результаты разведки: что смотрели, что нашли, на каких данных
приняты решения. Файл среза не правится после записи; новый взгляд — новый
файл с датой в имени `тема-ГГГГ-ММ-ДД.md`. Решения из срезов уезжают в
[journal.md](../journal.md), правила — в каноны зон.

- [reels-refs-2026-09-20.md](reels-refs-2026-09-20.md) — шесть рефов
  владельца, что общего у сильных, четыре гипотезы форматов, музыка.
- [music-and-formats-2026-09-20.md](music-and-formats-2026-09-20.md) —
  срез разведчика: музыка через Instagram Audio API и лицензии, форматы
  без лица, инструменты сборки видео из картинок и кода, требования
  Graph API к файлу и лимиты публикаций.
- [refs.md](refs.md) — реестр доноров формы: ролики без лица и
  «говорящая голова + новости» (русские и мировые кейсы, инструменты,
  право), дописывается.
- [2026-09-20-talking-head-news/](2026-09-20-talking-head-news/README.md) —
  пасс «говорящая голова + ИИ-новости»: 15 русских и 19 мировых кейсов,
  инструменты, цены и право; сырьё трёх разведчиков рядом.
- [2026-09-20-gus-formula/](2026-09-20-gus-formula/README.md) — формула
  «Новостного Гуся» с 31 ролика: 300 роликов по просмотрам, транскрипты,
  раскадровки, девять пунктов формы.
- [2026-09-21-viral-voice/](2026-09-21-viral-voice/README.md) — голос
  канала: 13 рефов «нейрослоп»-жанра, 15 движков русского синтеза с
  характером, рецепт «как у СЛОПа», сведение.
