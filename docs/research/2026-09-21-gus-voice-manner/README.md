## Вердикт

Голос Гуся — живой, собственный голос автора (Илья): пост
t.me/i11ush/2414 от 01.08.2026 — «фейка с моим голосом… нейронку,
которую натренировал на моём голосе». Манера — усиленное вдвое
финальное удлинение: последнее слово фразы 0,6 с против 0,28 с
(природная норма русского +40 мс), 164 слова в минуту за счёт
вырезанных пауз, а не быстрой артикуляции. Ни один синтез из
текста этого не даёт; клон Гуся — клон живого человека без согласия,
автор с таким уже воюет. Тема закрыта владельцем: «ладно, пофиг, не
надо» — за основу взят ровный Станислав в режиме без пауз, экспрессия
добавляется тегами и стабильностью.

## Что проверили и отвергли (по порядку)

1. Разметка удвоенных гласных в тексте v3 («тесст», «младенцааа») —
   эффект слабый и нестабильный (замер: +0,1…0,3 с, местами короче).
2. Монтажная растяжка гласного по таймкодам через `atempo` ×2–3 на
   куске 80 мс — «помехи»: WSOLA с окном ~82 мс дублирует фрагмент;
   забракован инструмент, не приём (без артефактов — `rubberband -3
   -M`, Praat DurationTier, pyworld; не проверено).
3. Замер 89 русских мужских голосов библиотеки по их образцам
   (отношение последнего слова к среднему, пауза после точки) — верх
   шестёрки tail 2,2–3,5 при паузах 0–0,7 с; владелец: «никто так не
   тянет». Замер по чужим образцам манеру не ловит.

## Если вернуться (условие возврата: владелец готов начитывать сам)

Единственный путь к живой просодии — voice changer ElevenLabs
(`eleven_multilingual_sts_v2`, русский, до 5 мин на сегмент): человек
читает в нужной манере, модель меняет только тембр. Второй —
Voiceover Studio «Generate Audio Fixed Duration» (последнее слово
фразы отдельным клипом 0,6 с; только интерфейс, в API не найдено).
Третий — Cartesia Sonic 3.6 с `<speed ratio="0.6"/>` перед последним
словом (вендор: «guidance, not strict»).

## Не найдено

Прямого интервью автора «озвучиваю сам» нет (вывод на сильных
косвенных). Работают ли теги темпа v3 на русском — нигде не сказано.
Публичных разборов просодии русских шортс-дикторов нет; наши цифры по
Гусю — единственные.
