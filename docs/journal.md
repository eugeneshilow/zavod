## 2026-09-13 21:09 · Codex · ⚖️ convex-without-login · Convex подготовлен, вход выполняет владелец

**Решение.** Установлены Next.js с App Router, React, TypeScript, Tailwind CSS, ESLint, Prettier, Vitest, MarkdownIt и Convex. Уже установленным Node.js и pnpm хватает совместимости, поэтому они сохранены; типы Node.js заменены на требуемую Vitest ветку как обязательная peer-зависимость. Каркас создан через scaffold-tmp с флагами --no-agents-md и --disable-git, затем перенесён в корень; шаблонный README, иллюстрации и Google Fonts удалены. Автозапись правил Next.js отключена через agentRules: false. Добавлены пустая схема Convex, клиентский провайдер с пропуском подключения при пустом URL и .env.local.example с пустыми переменными CLI. Главная и стекло читают проектные документы; проверка сохраняет результат локально. Флотские индексы документации обновляются командами docs:index и docs:decisions; самостоятельный запуск приложения от них не зависит.

**Отвергли.** Запуск входа Convex и создание облачной базы агентом: это решение о доступе к аккаунту владельца. Также пропущены серверные функции и их сгенерированные типы до появления deployment, remote, pull request, Vercel deployment и любые секреты в файлах. Условие возврата: владельцу понадобится живая база; тогда он запускает в корне проекта `npx convex dev`, входит в аккаунт и разрешает CLI заполнить игнорируемый .env.local. Бизнес-таблицы и функции добавляются по отдельным требованиям после подключения.

**Слова владельца.** «Do not run the Convex login: it creates a cloud deployment on the human's account, and that is an access decision.»

## 2026-09-13 21:05 · Codex · ⚖️ adopt-spec-driven-company · Истина живёт в документах, агенты исполняют, состояние видно

**Решение.** Проект zavod работает как Spec-Driven Company. Правила живут в `AGENTS.md`. Истина хранится в `docs/`: решения в этом журнале, краткое описание в `README.md`, устройство каждой зоны — в её документе. Агенты работают в ветках, пишут спецификацию до кода, запускают проверку перед каждым коммитом и останавливаются перед деньгами, ключами, персональными данными и публикацией наружу. Для этой первой локальной настройки владелец явно разрешил работу в текущей папке и один коммит на `main`, без remote, pull request и деплоя. Документы переводятся на русский; смысл правил и атрибуция исходного шаблона сохраняются.

**Отвергли.** Хранить истину в переписке и головах людей: она не переживает новую сессию агента или смену исполнителя. Продуктовые требования сверх локальной основы не добавляем: владелец их не задавал.

**Слова владельца.** «Set up Spec-Driven Company in this folder with the Next.js and Convex stack.» Дополнение: «плюс переведи доки сами доки внутри проекта на русский».
