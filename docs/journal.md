## 2026-09-19 21:40 · claude · ⚖️ go-online-github-vercel-convex · Проект живёт онлайн: приватный GitHub, Vercel, Convex в облаке

**Решили.** Код — в приватном репозитории `eugeneshilow/zavod-v6`; в `main` только слиянием pull request, и на каждый pull request и push в `main` GitHub Actions гоняет ту же `pnpm check`, что и человек. Хостинг — Vercel, привязанный к репозиторию: push в `main` собирает продакшен, pull request — превью; в продакшене сборка `pnpm check && npx convex deploy --cmd 'pnpm build'`, на превью `pnpm build`. База — Convex в облаке, деплои dev и продакшен; ключ продакшен-деплоя `CONVEX_DEPLOY_KEY` кладёт человек в Vercel сам. Иммунитет — почасовой `prod-alive` по адресу из `PROD_URL`. Канон — `docs/deploy.md`. Что человек делает дальше: создаёт deploy key в Convex и кладёт в Vercel; после слияния проверяет адрес продакшена и `/admin`.

**Отвергли.** Локальный бэкенд Convex — продакшену на Vercel не к чему подключаться. Публичный репозиторий — проект приватный, пока владелец не решит иначе. Сборка без проверки ради скорости — `/admin` показывал бы пустое стекло там, где статус нужнее всего.

**Слова владельца.** «Отвечай на языке этого промпта. Настрой Spec-Driven Company в этой папке со стеком Next.js и Convex и выведи проект онлайн: приватный репозиторий на GitHub, Vercel и Convex в облаке.»

## 2026-09-19 21:15 · claude · ⚖️ adopt-spec-driven-company · Истина живёт в docs, агенты исполняют, статус виден

**Решили.** Этот проект работает как Spec-Driven Company. Правила живут в `AGENTS.md`. Истина живёт в `docs/`: этот журнал — для решений, `README.md` — сводка на одну страницу, по файлу на зону — как что устроено. Агенты работают в worktree, пишут спеку раньше кода, запускают проверку перед каждым коммитом и останавливаются перед деньгами, ключами, персональными данными и всем, что публикуется наружу.

**Отвергли.** Держать истину в истории чата и в головах людей. Она не переживает новую сессию агента или нового человека.
