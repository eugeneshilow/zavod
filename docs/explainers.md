# explainers — объяснялки: горизонтальные ролики, нарисованные кодом

Дата: 2026-10-03. Как из одной темы получается обучающий ролик про ИИ:
закадровый голос объясняет, а на экране кодом рисуется то, о чём он
говорит, — в такт голосу. Жанр — 3Blue1Brown, образец формы — ролик Tibo
про Shazam ([срез](research/explainer-videos-2026-10-03.md)). Пишет
сценарий и сцены мозг [explainer](brains/explainer/README.md).

## Ролик

- **Кадр** — 1920×1080, 30 кадров в секунду, H.264 + AAC, `+faststart`.
- **Длина** — 60–80 секунд, ориентир 130–150 слов текста. Длиннее вышло —
  режут текст, а не ускоряют голос.
- **Вид** — тёмный фон, один тёплый акцент (золото), второй — бирюза,
  красный — только для ошибки. Подпись сверху по центру серифом, одна
  мысль, ключевое слово — цветом. Ни лиц, ни стоковых кадров. Палитра,
  шрифты и примитивы живут в `content/explainers/kit.js` и только там.
- **Форма** — один пример проходит через весь ролик, каждая сцена растёт
  из прошлой: то, что было на экране в конце сцены, стоит на том же месте
  в начале следующей.

## Папка ролика

Один ролик — одна папка `content/explainers/<id>/`, два файла.

`script.json` — сценарий:

| поле        | что это                                                                                  |
| ----------- | ---------------------------------------------------------------------------------------- |
| `id`        | имя ролика латиницей с дефисами; файл на выходе — `out/explainers/<id>.mp4`              |
| `title`     | название для людей                                                                       |
| `voice`     | `eleven:<voice_id>`; по умолчанию основной голос канала Stanislav ([reels.md](reels.md)) |
| `stability` | ровность голоса ElevenLabs, по умолчанию 0.5 — объяснялка читается спокойнее истории     |
| `tempo`     | темп голоса после синтеза, 0.85–1.15, по умолчанию 1.0                                   |
| `music`     | подложка из `assets/music/`, сводится тихо под голос; без поля — без музыки              |
| `scenes[]`  | сцены по порядку: `id` (имя функции в `scene.js`) и `say` — текст голоса с метками       |

**Метка** — `{имя}` перед словом в `say`: время метки — начало этого слова
в голосе. По меткам сцена знает, когда показать то, о чём говорит голос.
Голосу метки не уходят. Числа и латиница в `say` — словами («девяносто шесть
процентов», «Чат Джи-Пи-Ти»), правила разметки голоса — те же, что у
историй ([reels.md](reels.md), «Разметка для голоса»).

`scene.js` — сцены кодом: `window.SCENES = { <id сцены>: (ctx, s) => … }`.
Сцена рисует на холсте 1920×1080 и получает `s.t` — секунды от своего
начала, `s.d` — свою длину, `s.m` — свои метки и `s.p(метка, длительность)`
— плавный прогресс 0…1 от метки. Кадр — чистая функция времени: одно `t`
всегда даёт одну картинку, поэтому любой кадр можно снять отдельно.

## Как собирается ролик

1. Текст всех сцен склеивается через пустую строку (у eleven_v3 это
   пауза) и уходит в ElevenLabs одним запросом `with-timestamps`: в ответ
   приходит звук и время каждой буквы. Звук и времена ложатся в кеш
   `out/explainers/<id>/voice/` по тексту — пересборка картинки кредитов не
   тратит, правка одного слова переозвучивает весь ролик.
2. Из времён букв считается таймлайн: сцена начинается за 0.25 с до своего
   первого слова и идёт до начала следующей; метки — локальным временем
   сцены. До первого слова 0.4 с тишины, после последнего — 1.6 с.
   Таймлайн ложится в `out/explainers/<id>/timeline.json`.
3. Браузер (Playwright, chromium) открывает холст со шрифтами Literata,
   Inter и JetBrains Mono, рисует каждый кадр и отдаёт его ffmpeg трубой.
   Соседние сцены сменяются перекрёстно за 0.5 с.
4. ffmpeg сводит картинку, голос и музыку (громкость 0.07, затухание в
   последние 2 с), громкость всего — −16 LUFS.

Чистые функции рельсы — `scripts/explainers/timeline.mjs`, их держит
тест `tests/explainers.test.ts`. Сборка — `scripts/explainers/render.mjs`.

## Команды

- `node scripts/explainers/render.mjs content/explainers/<id>` — ролик с
  голосом.
- `--draft` — без голоса и без кредитов: тайминг по числу знаков (14 в
  секунду), звука нет. Для правки картинки.
- `--stills 3,12.5` — только кадры PNG в эти секунды, рядом с таймлайном.
  Ими сцену проверяют глазами до полной сборки.
- `--no-music` · `--out путь.mp4`.

## Края

- Голос — пока только ElevenLabs: SpeechKit не отдаёт времени слов, а без
  него анимация не попадёт в голос.
- Предел одного запроса — 4 500 знаков текста голоса: это минуты три, для
  объяснялки с запасом.
- Шрифты грузятся из Google Fonts при каждой сборке: без сети ролик
  соберётся системными шрифтами, и это видно.
- Сборка 80-секундного ролика — около полутора минут на Pro.
